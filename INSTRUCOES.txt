PERSONALIZACAO DO GITHUB - BERNARDO CIPOLLI

1) Acesse https://github.com/new
2) Crie um repositorio PUBLICO chamado exatamente BernardoCipolli.
   Marque Add a README file e confirme.
3) Edite o README.md da raiz e substitua pelo README.md deste pacote.
4) Envie o GIF: no repositorio, crie/envie o arquivo assets/animacao.gif.
   O pacote ja inclui um GIF animado roxo de exemplo.
   Para trocar, basta enviar outro GIF com o MESMO nome e caminho.
5) Crie um novo arquivo com o caminho EXATO:
   .github/workflows/snake.yml
   Cole nele o conteudo do arquivo snake.yml deste pacote e salve.
6) Acesse a aba Actions > Atualizar cobrinha roxa > Run workflow
   Selecione a branch principal e clique em Run workflow.
7) Ao concluir com sucesso, a branch 'output' sera criada
   e a cobrinha aparecera automaticamente no README.
8) Se houver erro de permissão no envio para a branch output:
   Settings > Actions > General > Workflow permissions
   > Read and write permissions > Save.
   Rode o workflow novamente.

Observacoes:
- O GIF e as estatisticas usam imagens; o README nao aceita JavaScript executavel.
- O GIF de exemplo e seu; pode ser substituido livremente.
- Os icones da secao 'Tecnologias para explorar' sao demonstrativos: ajuste.
- Cartoes de estatisticas dependem de servicos publicos externos e podem falhar temporariamente.
- A cobrinha somente aparece depois da primeira execucao bem-sucedida da Action.
- Se a Action nao aparecer, confira se snake.yml esta na branch padrao.
